# Support

## Documentation

The full documentation for `maltego-transforms` — setup, configuration,
authentication, entity modeling, pagination, and the complete API reference —
is available at:

https://docs.maltego.com/en/support/solutions/articles/15000062349-maltego-transforms-sdk-overview

## Getting help

- **Bugs and feature requests:** please open a
  [GitHub issue](https://github.com/maltegotech/maltego-transforms/issues) in
  this repository.
- **Usage questions:** check the documentation above first; if you're still
  stuck, open a GitHub issue with details of what you're trying to do.
- **Account or product support:** reach out through the
  [Maltego Support Portal](https://support.maltego.com/) or your Maltego
  account contact.

## Security issues

Please do not use these channels for security vulnerabilities — see
[SECURITY.md](SECURITY.md) instead.
